Traditional steady-state RTO — how it was built to work

  • Large first-principles or rigorous simulation model per unit
  • Solve economic optimum assuming steady state
  • Execute every 2–4 hours; push setpoints / bounds to MPC
  • Separate model team, separate APC team, separate planner
Designed for the 1990s operating model

When plants ran longer on stable feeds and optimization was a periodic advisory layer — not continuous profit execution.
